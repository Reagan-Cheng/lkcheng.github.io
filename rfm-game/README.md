# 最後一張優惠券 The Last Coupon

RFM 模型的課堂情境模擬遊戲，搭配團隊討論使用。學生扮演虛構品牌「楓巷咖啡」的會員經營小組，經營四個季度，每一季決定要對哪些會員分群發折價券或寄體驗禮，決定會影響下一季的會員狀態。

## 使用方式

- 網址：<https://reagan-cheng.github.io/lkcheng.github.io/rfm-game/>
- 建議每組共用一台裝置，全程約 45–50 分鐘。
- 右上角可切換中文與英文。進度存在瀏覽器裡，重新整理不會遺失；按「重新開始」可清除。

## 網址參數

| 參數 | 作用 |
|---|---|
| `?lang=zh` 或 `?lang=en` | 指定第一次開啟時的語言 |
| `?seed=7` | 換一批模擬會員（預設所有組別的會員資料相同，方便比較） |
| `?reset=1` | 清除這台裝置上儲存的進度 |

## 檔案結構

只有一個 `index.html`，不需要伺服器或建置步驟。檔案內有三段程式：

1. **ENGINE**：顧客模擬模型。相同的決定一定得到相同的結果。主要參數集中在開頭的 `P` 物件（預算、折價券面額、體驗禮成本等）。
2. **COPY**：全部的中英文文字。
3. **APP**：畫面與流程。

模型的運作邏輯與建議的時間分配，寫在結算頁最下方「給授課教師的說明」。

品牌、對手與人物皆為虛構。
